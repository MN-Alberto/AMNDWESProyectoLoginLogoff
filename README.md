# Aplicación Login / Logoff – DWES

Aplicación web desarrollada en PHP que implementa un sistema básico de **autenticación de usuarios**, permitiendo el **inicio de sesión (login)** y el **cierre de sesión (logoff)** mediante el uso de **sesiones**.

---

## 🎯 Descripción

Esta aplicación permite a los usuarios autenticarse mediante un formulario de login.  
Una vez autenticados, pueden acceder a zonas protegidas de la aplicación.  
El sistema controla el acceso mediante sesiones y permite cerrar sesión de forma segura.

---

## 🛠️ Tecnologías utilizadas

- PHP  
- MySQL / MariaDB  
- HTML5  
- CSS3
